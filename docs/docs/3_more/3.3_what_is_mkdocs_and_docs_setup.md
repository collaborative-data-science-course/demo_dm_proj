# What is MkDocs and How to Create Documentation with It

Writing clear and structured documentation is essential for any data science or software project. **MkDocs** makes this easy — it's a simple, static site generator designed for creating project documentation using Markdown.

---

## What is MkDocs?

**MkDocs** is an open-source tool that turns Markdown files into a beautiful and navigable documentation website.

-  Write docs in Markdown
- Host it as a website (locally or via GitHub Pages)
- Choose from themes like Material for MkDocs
- Organize large documentation with a simple `mkdocs.yml` file

---

## Why Use MkDocs?

| Feature                  | Benefit                                 |
|--------------------------|------------------------------------------|
| Markdown-based           | Easy to write and maintain              |
| Static site generator    | Fast and secure                         |
| GitHub Pages compatible  | Easy hosting for free                   |
| Themes & extensions      | Customizable and modern UI              |
| Navigation control       | Define menus easily in `mkdocs.yml`     |

---

## How to Set Up MkDocs

### 1. Install MkDocs

Use pip:

```bash
pip install mkdocs
```

Optional: Install the Material theme (recommended):

```bash
pip install mkdocs-material
```

---

## 2. Create a New MkDocs Project

Run this in your terminal:

```bash
mkdocs new my-docs
cd my-docs
```

This creates:

```
my-docs/
├── docs/
│   └── index.md
└── mkdocs.yml
```

- `docs/`: Where you write your Markdown documentation.
- `mkdocs.yml`: Config file for site name, theme, navigation, etc.

---

## 3. Run Local Server

Preview your site locally:

```bash
mkdocs serve
```

Open your browser and go to: `http://127.0.0.1:8000`
The site auto-reloads when you edit `.md` files.


---

## 4. Customize `mkdocs.yml`

Here’s a simple example:

```yaml
site_name: My Project Docs
theme:
  name: material

nav:
  - Home: index.md
  - Getting Started: getting_started.md
  - Models:
      - Training: models/train.md
      - Evaluation: models/eval.md
```

---

## 5. Add Markdown Files

Inside the docs/ folder:

- `index.md`: Your homepage
- `getting_started.md`: Another page
- Create subfolders like `docs/models/` and add more `.md` files

---

## Deploying Your Docs (Optional)

To generate a production-ready site:

```bash
mkdocs build
```

This creates a `site/` folder with static HTML files.

To deploy using GitHub Pages:

```bash
mkdocs gh-deploy
```

> This automatically builds and pushes your docs to GitHub Pages.

---

## Tips for Using MkDocs Effectively

- Use headings `(#, ##)` and bullet points to keep docs readable.
- Link pages with `[Link Text](other-page.md)`
- Organize your content in folders if docs grow big.
- Add images to `docs/assets/` and reference using relative paths:

```md
![Architecture](assets/diagram.png)
```

---

## Summary

- **MkDocs** is a simple and effective tool for creating static documentation.
- All you need are Markdown files and a YAML config.
- You can preview locally, customize with themes, and deploy online easily.
