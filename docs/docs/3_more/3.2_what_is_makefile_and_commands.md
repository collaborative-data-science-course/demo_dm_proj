# What is a Makefile and How to Create Custom Commands

Managing your data science or ML project often involves repetitive tasks like setting up environments, training models, or running tests. Instead of remembering long commands, you can use a **Makefile** to define shortcuts that simplify your workflow.

---

## What is a Makefile?

A **Makefile** is a simple configuration file used by the **`make`** tool to automate tasks.

- You define **rules** (commands) inside the Makefile.
- Each rule has a **name** (called a "target") and **shell commands** to execute.
- You run them by typing: `make <target>`

---

## Why Use a Makefile?

| Without Makefile                             | With Makefile                  |
|----------------------------------------------|--------------------------------|
| `python -m venv venv && source venv/bin/activate && pip install -r requirements.txt` | `make install` |
| `python src/train.py`                        | `make train`                   |
| `pytest tests/`                              | `make test`                    |

- Avoid remembering long shell commands
- Standardize workflow across your team
- Useful in automation and CI/CD

---

## Basic Makefile Structure

```make
# This is a comment
target_name:
    <shell command>
```
> Each command must be indented using a tab, not spaces.

---

## Example Makefile

```bash
# Create and activate a virtual environment, then install dependencies
install:
	python -m venv venv && source venv/bin/activate && pip install -r requirements.txt

# Run training script
train:
	python src/train.py

# Run tests
test:
	pytest tests/

# Clean generated files
clean:
	rm -rf __pycache__ .pytest_cache
```

---

## How to Use It

Run the following in your terminal from the project root (where the Makefile is located):

```bash
make install
make train
make test
make clean
```

---

## Pro Tips

1. You can set default targets by placing them at the top of the file.
2. You can define dependencies between targets (advanced).
3. Works cross-platform (use platform-agnostic commands where possible).
4. You can use .PHONY to mark targets that aren't files:

```bash
.PHONY: install train test clean
```

---

## Where to Place It

- Place the `Makefile` in your project root directory (same level as `README.md` and `requirements.txt`)

- No file extension is needed — it should just be called Makefile

```
your-project/
├── Makefile
├── README.md
├── requirements.txt
├── src/
│   └── train.py
└── tests/
```

---

## Summary

- A Makefile helps you automate and simplify tasks like installing, training, or testing.
- Use `make <command>` to run tasks defined in your Makefile.
- It's a powerful tool to make your workflows cleaner and more reproducible.
