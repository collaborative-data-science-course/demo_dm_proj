# What is DVC? Why Use It? And How to Set It Up

In data science and machine learning projects, tracking code using Git is not enough. You also need to track data files, model files, experiments, and pipelines. That’s where **DVC (Data Version Control)** comes in.

---

## What is DVC?

**DVC** stands for **Data Version Control**. It is an open-source tool that brings **Git-like versioning to data, models, and machine learning pipelines**.

Just like Git tracks code, **DVC helps track data, models, and other large files**, making your ML project fully reproducible and shareable.

---

## Why Use DVC?

| Problem                                     | How DVC Helps                             |
|---------------------------------------------|--------------------------------------------|
| Git is bad at handling large files          | DVC stores large files outside Git         |
| Data and models change frequently           | DVC tracks versions of data & models       |
| Teams need reproducible experiments         | DVC ensures reproducibility and consistency|
| Manual data copying across machines is messy| DVC manages and shares data across machines|
| ML pipelines get complex                    | DVC helps define and run pipelines cleanly |

---

### DVC + Git Workflow

1. Code is tracked by **Git**
2. Data/models are tracked by **DVC**
3. Meta files (like `.dvc`, `dvc.yaml`) are stored in **Git**
4. Actual large files are stored in **remote storage (e.g., Google Drive, S3, etc.)**

---

## How to Set Up DVC

### 1. Install DVC

You can install it using pip:

```bash
pip install dvc
```

Or if you're using a specific cloud remote (e.g., Google Drive, S3):

```bash
pip install 'dvc[gdrive]'
pip install 'dvc[s3]'
```

> Tip: Use a virtual environment for project dependencies.

---

### 2. Initialize DVC in Your Project

Make sure your project is already a Git repo.

```bash
git init               # if not already initialized
dvc init
git commit -m "Initialize DVC"
```

This creates a `.dvc` folder and modifies `.gitignore`.

---

### 3. Track a Data File or Folder

Let’s say you have a dataset in `data/`:

```bash
dvc add data/
```

This does three things:

1. Adds `data.dvc` — a small text file tracking data info
2. Adds `data/` to `.gitignore`
3. Keeps actual data out of Git!

Now you can:

```bash
git add data.dvc .gitignore
git commit -m "Track dataset with DVC"
```

---

### 4. Setup a Remote Storage (Optional but Recommended)

You can use any of the following as remote:

1. Google Drive
2. Amazon S3
3. Azure Blob Storage
4. SSH, local directory, etc.

Example for Google Drive:

```bash
dvc remote add -d myremote gdrive://<folder-id>
dvc push
```

This uploads data to remote storage. Teammates can later run:

```bash
dvc pull
```
…to download the same dataset locally.

---

## DVC vs Git for Data

| Feature           | Git             | DVC                          |
| ----------------- | --------------- | ---------------------------- |
| Track large files | Poor support  | Yes, with external storage |
| Version datasets  | Manual effort | Automated                  |
| Share data        | Difficult     | Push/pull from remote      |
| Integrate with ML | Limited       | Built for ML workflow      |

---

## Summary

- DVC helps you version and share datasets and models, just like Git does with code.
- Use `dvc init`, `dvc add`, and `dvc push` to start tracking large files.
- Setup remote storage to collaborate with your team effectively.
