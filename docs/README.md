Generating the docs
----------

Use [mkdocs](http://www.mkdocs.org/) structure to update the documentation. 

Build locally with:

    mkdocs build

Serve locally with:

    mkdocs serve

---

## Learning Path

 start serving:

    ```bash
    mkdocs serve
    ```

Visit `http://127.0.0.1:8000` to access the full educational guide.


or


Navigate to the `docs/` folder and start learning right away.
